# Global Services Placement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user put the global services box at the start or end of the rail or bar (four spots in the two-bar layout), from Settings, from the box's menu, or by dragging the box.

**Architecture:** One value type, `GlobalPlacement` (edge + bar, stored in `UserDefaults` through two `@AppStorage` keys), resolves to a `GlobalSpot` for each `RailLayout` and orders globals against a space's services. The views read it to draw one shared box view at the chosen end; `AppState.railServices` and the ⌘1–9 destinations read it to order shortcuts the same way. Dragging the box uses a new drag type whose drop targets appear only at the layout's allowed spots.

**Tech Stack:** Swift 6, SwiftUI, SwiftData (untouched), XCTest. Project generated by XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-26-global-services-placement-design.md`

## Global Constraints

- No change to any SwiftData `@Model`; the setting lives in `UserDefaults` only.
- Defaults are today's arrangement: edge `.start`, bar `.spaces`.
- Every macOS 26 symbol behind `#if compiler(>=6.2)`; the code must build under Xcode 16.2 (CI macOS 14 job). Known 16.2 rejections are in `CONTRIBUTING.md` under Build and test.
- Keep SwiftUI `body` modifier chains short; move new dialogs or `onChange` groups into a `ViewModifier` (see `RailMoveConfirmation`).
- New `.swift` files: run `xcodegen generate` and commit the regenerated `.pbxproj`.
- Test command: `xcodebuild test -project Chorus.xcodeproj -scheme Chorus -destination 'platform=macOS'`. Never add `-configuration Release`.
- Stage named paths only, never `git add -A`. Commit format `<type>: <description>`, ending with the `Claude-Session:` line.
- User-facing strings (picker titles, menu items, CHANGELOG, What's New) pass the mcp-humanizer check and Orwell's rules (repo `CLAUDE.md`).
- Run CI on the branch after each commit that touches Swift (`gh workflow run Test --ref feat/global-placement`).

## Review Focus

1. A user who picked "Right end of the services bar" and switches to "Rail on the left" expects the box at the bottom, and back again expects the right end, not the left. (Pinned by `testPlacementCarriesAcrossLayouts`, Task 1.)
2. Dragging one icon out of the box must still move that one service, not the box. (Checked live in Task 6, step list item c.)
3. Dropping the box anywhere that is not a spot leaves it where it was and changes no setting. (Checked live in Task 4, step 6.)
4. With no global services, nothing is drawn, no drop target appears, and the Settings picker still saves. (Task 3 step 4 check; Task 5 test.)
5. An overflowing top bar keeps the box and the nav buttons fully visible at either end; only the tabs scroll. (Checked live in Task 3, step 5.)

### Task 1: The placement model

**Files:**
- Create: `Chorus/Models/GlobalPlacement.swift`
- Create: `ChorusTests/GlobalPlacementTests.swift`
- Modify: `Chorus.xcodeproj/project.pbxproj` (via `xcodegen generate`)

**Interfaces:**
- Produces:
  - `enum GlobalEdge: String { case start, end }`
  - `enum GlobalBar: String { case spaces, services }` (meaningful in `.hybrid` only)
  - `enum GlobalSpot: Hashable, CaseIterable { case spaceStripTop, spaceStripBottom, servicesBarLeft, servicesBarRight, railTop, railBottom, barLeft, barRight }` with `var title: String` and `var edge: GlobalEdge`.
  - `struct GlobalPlacement: Equatable { let edge: GlobalEdge; let bar: GlobalBar }` with:
    - `static let edgeKey = "globalServicesEdge"`, `static let barKey = "globalServicesBar"`
    - `static let standard = GlobalPlacement(edge: .start, bar: .spaces)`
    - `init(edgeRaw: String, barRaw: String)` — unknown raw values fall back to `.standard`'s.
    - `static func spots(for layout: RailLayout) -> [GlobalSpot]` — in picker order.
    - `func spot(in layout: RailLayout) -> GlobalSpot`
    - `func placing(_ spot: GlobalSpot) -> GlobalPlacement` — returns a new value; a one-bar spot sets only `edge` and keeps `bar`.
    - `func ordered<T>(globals: [T], rest: [T]) -> [T]` — `globals + rest` at `.start`, `rest + globals` at `.end`.
    - `static func current(_ defaults: UserDefaults = .standard) -> GlobalPlacement` and `func save(to defaults: UserDefaults = .standard)`.

Spot titles (exact copy, run through the humanizer before committing): `spaceStripTop` "Above the spaces", `spaceStripBottom` "Below the spaces", `servicesBarLeft` "Left end of the services bar", `servicesBarRight` "Right end of the services bar", `railTop` "Top of the rail", `railBottom` "Bottom of the rail", `barLeft` "Left end of the bar", `barRight` "Right end of the bar".

Resolution table: `.hybrid` → `(spaces,start)` spaceStripTop, `(spaces,end)` spaceStripBottom, `(services,start)` servicesBarLeft, `(services,end)` servicesBarRight. `.sidebar` and `.allServices` → railTop / railBottom by edge. `.topBars` → barLeft / barRight by edge.

**Files:**

- Modify: `Chorus/Views/MainWindow/ContentView.swift` (hybrid case, `showsGlobals:` at ~244)

**Interfaces:**
- Consumes: `GlobalPlacement`, `GlobalSpot`.
- Produces: in `UnifiedRailView`, `@AppStorage(GlobalPlacement.edgeKey) private var globalEdgeRaw = GlobalEdge.start.rawValue` and `@AppStorage(GlobalPlacement.barKey) private var globalBarRaw = GlobalBar.spaces.rawValue`, and `private var globalPlacement: GlobalPlacement`. A `@ViewBuilder private func globalBox(axis: Axis) -> some View` that draws the global items (`railItemRow(item, in: .global)`) inside `ChorusCard.railPadding` and `.railCard()`, vertical or horizontal, and nothing when `globalItems` is empty. `SpaceStripView` reads the same two keys.

Placement rules per layout (from the spec):
- `.sidebar` (`verticalBody`): start = today's top position, now a card instead of rows-plus-`globalsRule`; end = after the scroll view, before `railRule` and `addServiceButton`. Delete `globalsRule` if nothing else uses it.
- `.allServices` (`allServicesBody`): start = first inside the scroll view (today); end = outside the scroll view, after it, before `allServicesAddButtons`. Pinned, not scrolling.
- `.topBars` (`horizontalBody`): globals leave `tabRow` (and its rule capsule). Start = a horizontal box before `tabStrip` (after the header and its divider); end = after `Spacer(minLength: 40)`, before `WebNavButtons`. The "+" stays inside `tabStrip`. Neither box scrolls.
- `.hybrid`: `ContentView` passes `showsGlobals: placement.bar == .services` to the services bar, which then follows the `.topBars` rules. `SpaceStripView` draws the `globalsOnly` `UnifiedRailView` only when `bar == .spaces`: before the `ScrollView` at start (today), or after the `ScrollView` and before the hairline and `addSpaceButton` at end.
- Keep `ReorderKey` animations keyed on the ids drawn in each list; the globals' key moves with the box.
